# CEPA Security Architecture & Threat Model

> **SIH 2026 Problem Statement 26031**: Quality assessment and grading of onions  
> **Security Classification**: OWASP Top 10 Aligned

---

## 1. Security Policy & Responsible Disclosure

The CEPA engineering team prioritizes system integrity and secure field operations. If you discover a vulnerability in the cryptographic seal chain, optical validation gate, or API endpoints, please report it privately:

- **Security Contact**: Report vulnerabilities privately via GitHub Security Advisories (or direct maintainer contact).
- **Response SLA**: Initial triage within 24 hours; patch deployed within 72 hours for high/critical vulnerabilities.
- **Scope**: All backend API services, cryptographic seal engines, and mobile client authentication boundaries.

---

## 2. Formal STRIDE Threat Model

Agricultural quality assaying directly dictates procurement pricing and Price Stabilisation Fund (PSF) government disbursements. The system enforces strict defense-in-depth across all STRIDE threat categories:

| Threat Category | Specific Mandi Attack Vector | CEPA Mitigation Architecture | Verification Mechanism |
| :--- | :--- | :--- | :--- |
| **Spoofing** | Presentation attack using stock onion photos or AI-generated synthetic crops. | Dual-stage Deep Botanical Authenticity Gate (`MobileNetV3` + HSV anthocyanin/quercetin wavelength verification). Rejects non-food objects. | Unit & integration tests in `test_onion_validator.py`. |
| **Tampering** | Man-in-the-middle alteration of equatorial caliper measurements or grade outputs. | Immutable HMAC-SHA256 Tamper-Evident Cryptographic Seal calculated at finalize time and locked into SQLite with WAL persistence. | Public tamper audit endpoint `GET /api/v1/reports/{id}/verify`. |
| **Repudiation** | Mandi procurement officer denies grading appraisal or farmer disputes payout deduction. | Cryptographic seal binds raw tray photo SHA-256 digest, officer identity, timestamp, and dockage calculations into a tamper-evident digital token. | Mathematical recalculation matches stored 64-character hex signature. |
| **Information Disclosure** | Leakage of farmer personal identity, geolocation coordinates, or bank identifiers. | Geolocation coordinates and farmer IDs are scoped; sensitive officer secrets are stripped from all public serialization schemas (`InspectionSummary`, `ReportDetail`). | Pydantic response filtering and strict schema validation. |
| **Denial of Service** | Uploading massive image payloads or bombarding heavy CV segmentation pipeline. | Maximum payload bounds (10MB per image), request timeout guards (45s Render wakeup / 180s upload controller), and upload idempotency via image SHA-256 deduplication. | `Sample` model duplicate digest detection in `inspection_service.py`. |
| **Elevation of Privilege** | Unauthenticated callers invoking destructive demo database wipe endpoints. | Strict `verify_officer_token` FastApi dependency protecting `POST /demo/seed-inspection?force_reprocess=true` and finalize routes. Separate HMAC seal key from officer API key. | `test_audit_remediation.py::test_seed_inspection_requires_officer_token_when_enforced`. |

## 3. Tamper-Evident Cryptographic Seal Specification

Every official certificate generated by CEPA is secured by a tamper-evident cryptographic seal compliant with FIPS 198-1:

$$\text{Seal} = \text{HMAC-SHA256}\Big(K_{\text{seal}}, \; H(\text{Image}) \parallel \text{LotID} \parallel \text{GradeA\%} \parallel \text{URS\%} \parallel \text{Reject\%} \parallel \text{NetRate} \parallel \text{OfficerID} \parallel T_{\text{final}}\Big)$$

Where:
- $K_{\text{seal}}$ is a high-entropy secret decoupled from officer bearer credentials.
- $H(\text{Image})$ is the SHA-256 cryptographic digest of the raw optical tray image on physical disk.
- If the image file is missing or altered, the seal status transitions immediately to `INVALID_MISSING_PHOTO` or `SEAL_TAMPERED`.

## 4. Optical Replay & Physical Tamper Defenses

1. **ChArUco Metric Scale Protection**:
   - The system validates that the 7x5 ChArUco board occupies a physically reasonable bounding ratio ($> 5\%$ of frame span).
   - If an adversary crops out the board or uses an arbitrary reference, the system downgrades confidence to `NO BOARD DETECTED [NEEDS REVIEW]` with expanded uncertainty bounds ($\pm 5.0\text{ mm}$).
2. **Resolution-Invariant Parallax Bounds**:
   - Camera tilt angles $> 30^\circ$ and optical distance anomalies are detected via homography decomposition.
3. **Storage Eviction Transparency**:
   - On ephemeral cloud hosts (e.g. container redeploys), certificates transparently state `PHOTO_RECORDED_FILE_EVICTED` rather than fabricating synthetic hashes.

---

## 5. Key Rotation & Environment Hardening

- In production deployments, `OFFICER_API_KEY` and `HMAC_SEAL_SECRET_KEY` are provisioned via cryptographically random 32-byte hexadecimal strings generated in secure container environments.
- Mobile client bundles never store server-side HMAC secret keys; mobile clients only receive public verification tokens and QR URLs.
